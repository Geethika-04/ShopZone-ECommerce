# 🛒 ShopZone - E-Commerce Application

ShopZone is a full-stack E-Commerce web application built using **Java, Spring Boot, Spring Data JPA, MySQL, HTML, CSS, JavaScript, and Bootstrap**.

The project demonstrates how a modern web application connects a frontend with a RESTful backend and a relational database.

---

## 📌 Project Overview

ShopZone allows users to:

- View available products
- View product price and stock
- Add products to cart
- View shopping cart
- Remove products from cart
- Proceed to checkout
- Enter customer details
- Place an order
- Store products and orders in MySQL

The application follows a simple layered architecture:

Frontend
   ↓
Spring Boot REST API
   ↓
Spring Data JPA
   ↓
